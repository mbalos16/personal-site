# Maria Balos — Personal Portfolio

Personal portfolio site for Maria Balos, Data Scientist based in Cambridge, UK. The site showcases data science projects, UX design work, and professional experience.

Live at: [mariabalos.art](https://mariabalos.art)

## Tech Stack

- HTML5 / CSS3
- Bootstrap 5
- p5.js
- Hosted via GitHub Pages

## Structure

| File / Folder | Description |
|---|---|
| `index.html` | Homepage — about me and blog posts |
| `python.html` | Data science and python projects |
| `projects.html` | UX design projects |
| `resume.html` | Resume / CV |
| `style.css` | Global stylesheet |
| `img/` | All site images |

## Running Locally

No build step required. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mbalos16/personal-site.git
cd personal-site
open index.html
```
