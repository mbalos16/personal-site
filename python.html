Computer Vision · Research · PyTorch

Replicating and extending the results from the Manifold HyperConnections paper (arXiv:2512.24880) for computer vision tasks. Original work exploring how mHC applies beyond the settings covered in the paper.

Computer Vision · PyTorch

10 CNN architectures implemented from scratch in PyTorch — from LeNet to ViT — including custom variations, all benchmarked on the NEU Surface Defects dataset with a shared modular trainer and CLI interface.

Ryanair Timecapsule

Data Collection · Open Source

Reverse-engineered the Ryanair API (Fare-Finder and Booking endpoints) to collect daily flight prices. Released as an open-source Python package with tests, CLI scripts, and a proper src layout.

GitHub

RAG-Driven Educational Assistant

Master's Dissertation — Deep Learning & Generative AI

Full-stack RAG application that ingested ~364 hours of video content (91 lessons) via Whisper transcriptions. Built with LangChain, ChromaDB, GPT-4o-mini and Claude-3-Haiku, with a gamified student leaderboard benchmarking human performance against the RAG system.

GitHub · Video presentation

Datamecum Datathon — 1st Place

Machine Learning · Competition

Won 1st place in a Kaggle-style binary classification competition with an ensemble of Random Forest and XGBoost (AUC 0.9851). Included EDA, self-organising maps, correlation analysis, and ensemble modelling.
